caseStudy:
  pt:
    context: A operação de eventos dependia de planilhas para organizar
      colaboradores e informações, tornando o acompanhamento das inscrições e da
      presença mais trabalhoso.
    challenge: Centralizar os dados dos eventos e colaboradores em um único
      ambiente, reduzindo tarefas manuais e facilitando o acompanhamento da
      operação.
    solution: Foi desenvolvido um sistema de gestão com painel administrativo,
      gerenciamento de eventos, inscrições públicas e recursos para acompanhar
      colaboradores e exportar informações.
    role: Desenvolvimento individual fullstack, incluindo frontend e backend.
    features:
      - Criação e gerenciamento de eventos.
      - Links públicos para inscrição de colaboradores.
      - Controle de vagas e cotas femininas.
      - Identificação de colaboradores por fotografia.
      - Marcação de presença.
      - Visualização centralizada das informações.
      - Facilidade para copiar chaves PIX.
      - Exportação de dados para Excel e PDF.
    architecture: Aplicação web com área administrativa para gerenciamento dos
      eventos e interface pública para inscrição de colaboradores.
    challenges: []
    results:
      - Centralização das informações de eventos e colaboradores.
      - Redução da dependência de controles manuais em planilhas.
  en:
    context: Event operations relied on spreadsheets to organize staff and event
      information, making registration and attendance tracking more
      labor-intensive.
    challenge: Centralize event and staff data in one environment, reducing manual
      tasks and making operational tracking easier.
    solution: A management system was developed with an administration panel, event
      management, public registration flows, staff tracking, and data export
      features.
    role: Sole full-stack development, including frontend and backend.
    features:
      - Event creation and management.
      - Public registration links for staff.
      - Vacancy and female-quota management.
      - Staff identification by photograph.
      - Attendance tracking.
      - Centralized information view.
      - Quick copying of PIX keys.
      - Excel and PDF data exports.
    architecture: A web application with an administration area for event management
      and a public interface for staff registration.
    challenges: []
    results:
      - Centralized event and staff information.
      - Reduced reliance on manual spreadsheet-based controls.
